# Final Publish Checklist

Use this checklist immediately before creating the public repository or pushing the first public commit.

## Repository Surface

- confirm `README.md` is the final public landing page
- confirm `README.zh-CN.md` matches the current positioning
- confirm `REPO-METADATA.md` reflects final description, homepage, and topics
- confirm `LICENSE` is present and correct

## Product Story

- confirm the MyClaw.ai ecosystem positioning is visible but not overbearing
- confirm the repository clearly explains that it improves engineering behavior, not model weights
- confirm OpenClaw remains the primary task context

## Content Hygiene

- confirm no secrets or internal-only details leaked into examples, evaluation files, or references
- confirm release notes and versioning documents are aligned
- confirm there are no stale paths or missing file links in README

## First Public Push

- create the GitHub repository
- apply description, homepage, and topics from `REPO-METADATA.md`
- push the repository contents
- review the repo page once live to ensure the landing experience reads cleanly
