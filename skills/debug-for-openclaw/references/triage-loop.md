# Triage Loop

## Loop

1. reproduce
2. localize
3. reduce
4. hypothesize
5. patch narrowly
6. verify
7. guard

## Stop Conditions

Stop and re-plan when:

- the failure spans multiple systems and the boundary is unclear
- each attempted fix increases uncertainty instead of reducing it
- the observed symptom changes but the root cause is still unknown

## Rule

A fast wrong fix is usually slower than one careful reproduction cycle.
