# Interaction Regression Checks

## Core Checks

- click targets still trigger the intended behavior
- keyboard and focus movement remain sensible where relevant
- visible feedback matches state changes
- no hidden dependency on a stale component state
- no dead-end path after error or cancel actions

## Visual Sanity

- critical controls remain visible
- labels still match action intent
- spacing or layout changes do not hide logic errors

## Rule

Do not confuse visual polish with interaction correctness.
