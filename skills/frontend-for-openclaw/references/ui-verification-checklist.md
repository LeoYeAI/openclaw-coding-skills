# UI Verification Checklist

## Core Flow

- the changed interaction completes successfully
- loading, success, and error states are sensible
- visible copy matches the intended behavior

## Layout

- key content remains usable on desktop
- key content remains usable on mobile-sized layouts
- no obvious overlap, clipping, or dead controls

## Interaction

- focus and click targets behave predictably
- state updates are visible and understandable
- no critical path depends on hidden assumptions
