# Task Shapes

## Direct Edit

Use for small work with narrow scope and obvious verification.

Pattern:

1. read
2. edit
3. verify
4. close out

## Planned Task

Use when the task crosses files, steps, or risk boundaries.

Pattern:

1. define the slices
2. track them in `plan.md`
3. complete one slice at a time
4. verify each slice
5. close out cleanly

## Delegated Task

Use a spawned coding session when isolation or parallel execution improves speed without reducing control.
