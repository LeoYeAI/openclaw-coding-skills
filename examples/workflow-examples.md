# Workflow Examples

## `openclaw-dev-workflow`

Most likely trigger for requests like:

- Build this feature properly from start to finish.
- Fix this issue across the codebase and make sure we do not miss anything.
- I need this implemented cleanly, tested, and ready to hand off.
- Handle this coding task end to end.
- Help me ship this safely without cutting corners.

## `spec-for-openclaw`

Most likely trigger for requests like:

- Before we write code, help me define exactly what this feature should do.
- Turn this rough idea into something engineering can build.
- Write a spec for this workflow change.
- Clarify the scope, constraints, and acceptance criteria first.
- I do not want coding yet, I want the implementation target nailed down.

## `plan-for-openclaw`

Most likely trigger for requests like:

- Break this into implementation steps.
- Make me a plan for this refactor.
- Split this work into tasks we can execute one by one.
- What order should we build this in?
- Turn this spec into a task list with checkpoints.

## `build-for-openclaw`

Most likely trigger for requests like:

- Implement this change without rewriting half the system.
- Add this behavior and keep the diff tight.
- Wire this feature into the existing flow.
- Make the code change for this one part first.
- Patch this carefully and verify each step.

## `test-for-openclaw`

Most likely trigger for requests like:

- What is the minimum proof we need before we merge this?
- Verify this actually works.
- What tests should we add for this bug fix?
- I do not trust this change yet. How should we prove it?
- Is this ready, or is the evidence still weak?

## `review-for-openclaw`

Most likely trigger for requests like:

- Review this PR like a strict engineer.
- Look for regressions in this implementation.
- Audit this change for bugs and weak assumptions.
- Sanity-check this before we merge it.
- Tell me what is risky or under-tested here.

## `ship-for-openclaw`

Most likely trigger for requests like:

- Wrap this up cleanly.
- Are we ready to ship this change?
- Prepare the final handoff with risks and verification.
- Do the last pass before release.
- Close this out without leaving loose ends.
