# Example Tasks

This directory contains realistic user requests for trigger calibration.

The goal is not to test model intelligence in the abstract. The goal is to make sure the right skill is likely to activate for the right kind of request.

## How To Use

- Compare a real user request against these examples.
- Check whether the most likely skill is obvious.
- If a request feels ambiguous, improve the relevant skill description or the trigger matrix.
- Add new examples when repeated real-world phrasing appears.

## Structure

- `workflow-examples.md`: broad planning, implementation, testing, review, and ship requests
- `specialist-examples.md`: debugging, security, frontend, docs, deploy, and refactor requests
