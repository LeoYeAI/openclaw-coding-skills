# Quickstart

Use this path if you want to try the repository with minimal setup.

## 1. Start Small

Adopt this set first:

- `openclaw-dev-workflow`
- `plan-for-openclaw`
- `build-for-openclaw`
- `test-for-openclaw`
- `review-for-openclaw`
- `ship-for-openclaw`

## 2. Add Specialists Only When Needed

Add these if your work frequently touches them:

- `debug-for-openclaw`
- `security-for-openclaw`
- `deploy-for-openclaw`
- `frontend-for-openclaw`
- `refactor-for-openclaw`

## 3. Use The Trigger Layer

Keep these files nearby when tuning:

- `skills/TRIGGER-MATRIX.md`
- `examples/README.md`
- `evaluation/README.md`

## 4. Run One Dry Validation

Review:

- `evaluation/VALIDATION-SUMMARY.md`
- `evaluation/ambiguity.jsonl`

## 5. Run Real Tasks

Record real-task observations with:

- `evaluation/LIVE-VALIDATION.md`
- `evaluation/live-results-template.jsonl`
- `evaluation/tuning-log-template.md`

## Rule

Do not try to perfect everything before using it. Install, try a few real tasks, then tune only the weak boundaries you actually observe.
