# Release Notes

## Version 0.3.0

This release turns the repository from a basic skill collection into a structured coding-optimization system for OpenClaw.

### Added

- workflow skills for spec, plan, build, test, review, and ship
- specialist skills for debug, security, frontend, docs, deploy, and refactor
- reference materials that provide execution scaffolding instead of abstract advice only
- trigger matrix for request-to-skill mapping
- realistic examples for trigger calibration
- labeled evaluation datasets for iterative tuning
- ambiguity dataset for boundary-case trigger analysis
- tuning playbook and result schema for a repeatable feedback loop
- deeper reference layers for high-risk and high-frequency skill families

### Practical Outcome

The repository now supports four levels of improvement:

- better default engineering behavior
- stronger decision support during execution
- better automatic skill triggering
- repeatable tuning of trigger quality over time
